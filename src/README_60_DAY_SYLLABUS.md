# Kotlin 60-Day Syllabus (Full Stack)

Structure:
- `week01` to `week08`
- Each day has one Kotlin file with:
  - Topic heading
  - Minimal starter code
  - Topic-related practice questions in comments

Flow:
- Week 1: Setup, Syntax, Arrays
- Week 2: Control Flow, Functions
- Week 3: OOP
- Week 4: Collections, Generics
- Week 5: Null Safety, File I/O
- Week 6: Coroutines, Flow
- Week 7: Android UI, Architecture
- Week 8: API, Testing, Capstone
